# SIGNAL-4D V7 external How2Sign residual transport: preregistration

Lock date: 2026-08-21 (Asia/Ho_Chi_Minh)

## Objective

Evaluate a V7 upper-body module whose learned parameters were fitted and
selected without any SGNify target. The frozen checkpoint was trained on
346,304 How2Sign frames and selected on 15,936 source-disjoint How2Sign
validation frames. SGNify contributes image observations only at inference.

The checkpoint predicts bounded local SO(3) residuals from image-derived
whole-body confidence, presence, temporal motion, and reprojection residuals.
It does not replace the SMPL-X expert.

## Locked integration

The pre-existing checkpoint inference gives a refined Lane rotation
`R_ext` relative to its frozen initializer `R_init`. For each selected
upper-body joint, transport the residual to V6:

`DeltaR = R_ext R_init^T`, `R_V7 = DeltaR R_V6`.

Use full residual scale `alpha=1`, because that is the externally selected
checkpoint output; no SGNify alpha search is permitted. Transport only spine,
neck, collar, shoulder, and elbow joints listed in the machine-readable config.
Keep V6 root, lower body, face, eyes, and all local hand rotations. After the
parent-chain update, solve both local wrist rotations so that their global
orientations are exactly V6. Keep V6 shape, expression, and translation.

No hard frame router is trained. The checkpoint's own bounded rotation and
safety-fallback contract remains active. Every final mesh is generated by one
coherent SMPL-X forward pass; no vertex splicing is allowed.

## Locked evaluation

1. Commit code, tests, config, and this document before author evaluation.
2. Produce exactly 57 signs and 1,493 frames in an append-only output.
3. Verify zero target fields in every inference cache and exact V6 frame IDs.
4. Verify unchanged closed rotations and global wrist errors below `1e-5`.
5. Run the unmodified author evaluator with `frame-policy=manifest` once.
6. Report All, UBody, UBody-F, LHand, RHand, coverage, and exact hashes.

Primary success is lower UBody-F than V6 without material hand regression.
The result is retained even if negative; no alpha, joint-set, or checkpoint
changes are allowed after evaluation.

## Claim boundary known before evaluation

This construction meets “no SGNify training or calibration.” It is not a
literally pristine benchmark because earlier V5–V7 and Phase-2 work had already
inspected SGNify metrics, including an older direct application of this
checkpoint to a different baseline. Any paper must disclose that history and
should confirm the final method on an additional sealed dataset. The new
official-author evaluation below is still valid as a reproducible same-protocol
comparison; it is not evidence of an untouched test-development process.

## Post-lock outcome

The implementation was locked in commit
`5f9f7a35ce2d2c5a4d4478f552ef4a7205bc3006` before the official evaluation.
The run covered all 57 signs and 1,493 frames. Relative to V6, it changed
author-protocol UBody-F from 29.519389 to **29.368032 mm** and UBody from
26.139380 to **25.983900 mm**. LHand changed by +0.000181 mm, RHand by
+0.002809 mm, and All regressed by +0.265349 mm.

The preregistered primary upper-body condition passed; a full-body-improvement
claim did not. No locked hyperparameter or joint set was changed after seeing
the result. The full protocol, uncertainty, reproducibility, validity scan, and
claim boundary are recorded in
`SIGNAL-4D_V7_external_How2Sign_author_protocol_report_2026-08-21.md`.
